# ArtJSM Theme

Плагин редизайна для **Jira 8.21.1** и **Jira Service Management 4.21.1**. Байткод собран под **Java 8**. Плагин не меняет логику Jira: он подключает стили и переключатель темы.

Светлая тема приводит шапку, навигацию, кнопки, таблицы, диалоги и портал службы поддержки к спокойному виду со скриншота: синяя шапка `#0747A6`, белый холст, скруглённые кнопки `#0052CC`, активный раздел с синим подчёркиванием. Тёмная тема использует те же компоненты на тёмном фоне.

## Установка

```bash
mvn -B package
```

В Jira: **Администрирование → Приложения → Управление приложениями → Загрузить приложение** и выберите `target/artjsm-theme-1.0.1.jar`. Это плагин версии 2, поэтому UPM ставит его без перезапуска. После установки обновите страницу.

Посмотреть стили без Jira можно в `src/test/preview/index.html`. Параметр `?theme=dark` открывает тёмную тему.

## Тёмная тема

В правой части синей шапки есть кнопка с луной. Повторное нажатие возвращает светлую тему. Выбор пишется в `localStorage` и, для вошедшего пользователя, в свойство пользователя Jira `artjsm.theme`, поэтому тема подхватывается в другом браузере. Если выбор ещё не сделан, плагин следует настройке системы (`prefers-color-scheme`).

Свои экраны могут опираться на атрибут `html[data-artjsm-theme="dark"]` и переменные `--artjsm-bg`, `--artjsm-surface`, `--artjsm-text`, `--artjsm-link`, `--artjsm-primary`, `--artjsm-border`.

## Ограничения

Редактор в iframe (TinyMCE) и виджеты с других адресов не получают эти стили. У приложений со своими жёстко заданными цветами тёмная тема покроет стандартные компоненты AUI, а собственные блоки лучше красить через переменные выше.
